# AI分类、专属档案和公开资料补充

实现范围包含CHG-T05-004、T09-002、T10-002、T11-002、T13-002、T14-002、T15-001、E01-001，以及2026-11-16新增的模型界面、全历史导入整理和E02确认关联子项。默认关闭自动整理和联网，所有事实候选需要核实；发送功能保持关闭。

## 本机模型与搜索配置

先在“设置 → AI 模型”保存模型地址、名称、密钥和每日额度；密钥由本机后台加密保存，不回显。也兼容[AI模型接入](ai-setup.md)的环境变量方式，已保存配置优先。模型需要支持兼容Chat Completions的非流式JSON输出。页面的模型表单仅接收模型密钥，平台或搜索密钥继续在本机后台配置。

联网资料使用独立[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)，需要本机`TAVILY_API_KEY`。模型本身不被当作已经联网。未配置搜索时，人工档案与已配置模型的聊天整理仍可使用，公开搜索显示未配置。

可在PowerShell 7启动后台之前输入搜索密钥（输入会遮挡，不把实际值写入命令历史）：

```powershell
$env:TAVILY_API_KEY = Read-Host 'Tavily API Key' -MaskInput
$env:PUBLIC_SEARCH_DAILY_LIMIT = '20'
.\scripts\start-inbox.ps1
```

模型每日尝试额度可在设置修改，未保存时沿用`AI_DAILY_LIMIT`，默认50；搜索独立默认20次，`PUBLIC_SEARCH_DAILY_LIMIT`允许1—1000。额度保存在加密库，失败外呼仍占用已预留次数，重启不能重置。额度用尽的作业等待上海时区下一天。模型/搜索供应商的真实计费与服务可用性需要自行核验；本次工程验证没有调用真实收费服务。

项目不会自动读取.env；.env.example只是字段说明。更新代码后重启旧后台，再在设置使用本次令牌连接。

## 使用

1. 打开“联系人”，或在“消息”选择一个会话后打开“个人档案”。同名联系人按平台账号及会话分开，不自动合并。
2. 人工填写备注、分类覆盖、公开姓名/公司/职位；未配置模型也能保存人工资料。
3. 查看当前模型和处理范围后，明确允许自动整理，或点击一次整理。开启后后台对新消息提交持久作业，页面关闭不取消已授权任务；已有AI设置为暂停时不会执行。
4. 需要联网时明确填写公开搜索姓名并授权。搜索仅发送公开姓名/公司及职业作品关键词，不发送聊天原文、私人备注、平台账号ID或密钥。返回来源的URL、标题、片段、时间与指纹保留。
5. 查看AI建议分类、摘要和待核实事实。公开同名匹配不代表同一个人；核对证据与来源后明确确认或拒绝，模型不能自己确认。
6. 专属文档区分人工资料、已确认、AI建议、待核实和来源。文档保存在产品SQLCipher库；只有点击导出才生成Markdown下载，不自动写入仓库。

手工分类优先，AI不会覆盖人工备注或已确认事实。会话列表可按分类筛选，未整理显示“未分类”。换模型目标后，旧的自动授权不会自动迁移；需要明确确认新的目标。

## 范围和失败处理

自动整理按已入库消息的本地序号升序分批，每批最多20条、序列化消息约20KB；下一批承接前批摘要，成功后推进实际批尾，重开继续未处理部分。个人档案显示“已处理/总条数”。确认事实另有数量/字节上限，档案查询也有事实/来源上限并显示截断；逐批覆盖全部已入库文本不代表平台全部历史已获取、附件已识别或长期摘要无损。手动“一次整理”仍取近期窗口，不推进自动水位。追加消息继续调度，人工修改或暂停拒绝旧结果。

导入时勾选“导入后自动整理”，查看目标模型及数据范围并确认。后台将昵称、平台ID、用户提供的备注及当前批聊天提交给所选模型，按稳定平台身份归入原档案；同名不会自动归为一个人。消息导入、授权与排队在同一事务，模型配置已变或涉及暂停会话时整批拒绝，修正后再明确提交。不勾选时仅保存消息，不调用模型；普通同步也不会替未授权联系人开启AI。

在个人档案的“合并同一人的聊天档案”核对建议，确认属于同一人后关联。建议来自相同昵称、公开姓名或相同平台账号，跨平台同ID不能证明身份。关联后可一起查看与导出联合Markdown，也可解除；原消息、事实证据和各会话AI权限独立，联合文档不被用作跨联系人模型输入。当前只汇总直接确认的关联，不传递推断第三人身份。

超长单条消息会显示失败而不跳过；请先核对原文并决定是否缩减导入文本。网络等暂时故障使用有界重试，最多三次尝试，可能重复计费；额度不足等待次日。后台暂停、关机或休眠期间不执行，运行窗口不等于平台获取完整历史。

作业有去重、租约、尝试次数和有界退避，恢复只处理仍获授权的作业；成功监听后才启动收费AI。关闭服务会取消本机执行，不能撤回已发送给供应商的数据或保证供应商停止计费。自动资料作业不执行发送或其他平台操作。

检索仅使用公开索引的有界片段，不登录私人账号、不绕访问控制、不提取隐藏身份，不搜集个人联系方式、私人位置或敏感身份推断。源网页/聊天里的指令都不改变模型权限。无可用结果如实显示，不生成假来源。

真实模型、Tavily和真人页面效果仍待配置后验收。负责人/指定审查及实际检查见[验证记录](acceptance/T09-ai-profiles-validation.md)和[ADR0009](adr/0009-ai-contact-profiles.md)。
