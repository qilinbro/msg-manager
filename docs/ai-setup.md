# AI 管理接入说明

2026-11-12 · FEAT-T09—FEAT-T14 · 手动分析与草稿首版，正式审查和真实模型验收待进行。

可把已导入或同步到消息中心的一段会话交给 DeepSeek 或兼容服务，保存摘要、风险提示、回复草稿和待核实记忆。当前不自动接管聊天或发送消息。

## 本机配置

在启动后台的 PowerShell 7 终端设置环境变量。项目不自动读取 `.env.example`，不要将真实密钥写进仓库：

```powershell
$env:AI_BASE_URL = 'https://api.deepseek.com'
$env:AI_MODEL = Read-Host '填写控制台当前可用的模型ID'
$aiSecret = Read-Host '填写模型API密钥（隐藏输入）' -AsSecureString
$env:AI_API_KEY = [System.Net.NetworkCredential]::new('', $aiSecret).Password
$env:AI_DAILY_LIMIT = '50'
.\scripts\start-inbox.ps1
```

密钥存在该终端和后台进程的环境中；不要截图、填写到工作台或提交配置值。重启后台后配置才生效。数据库密钥仍由现有脚本准备，模型密钥与数据库密钥、平台令牌、本产品访问令牌分别管理。

- `AI_BASE_URL`：公网 HTTPS 根路径或 `/v1`，后台追加 `/chat/completions`。拒绝用户名、查询串、重定向、代理、局域网目标和任意路径。
- `AI_MODEL`：实际提供商当前支持的模型 ID，不预置默认值。
- `AI_API_KEY`：HTTPS 必填，只由后台发送给固定服务；不进入模型输入、不返回前端。
- `AI_DAILY_LIMIT`：1—1000，缺省50。按 Asia/Shanghai 自然日持久化累计尝试次数，失败或超时也计数。这是次数限制，不是金额预算；提供商自身可能另有费用和速率限制。

兼容服务需支持非流式 Chat Completions、`response_format: {"type":"json_object"}` 和单条 assistant 文本结果。仅 `api.deepseek.com` 增加 `thinking: {"type":"disabled"}`；其他兼容服务不加此专属参数。当前无工具调用、Responses、图片/音频输入或任意网关路径，不能保证所有标称“兼容”的服务都可用。JSON 输出、模型 ID 和思考模式参照 [DeepSeek 官方接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

三个配置均留空时关闭模型调用，仍可管理消息、查看已有结果和记忆；不完整或不安全配置导致后台启动失败，错误不回显密钥。本机模拟器仅接受显式 `http://127.0.0.1:端口` 或 `http://[::1]:端口`，允许空密钥；不接受 `localhost`、其他本地地址和 HTTP 公网。

## 工作台步骤

1. 启动前端并连接本机服务，先导入聊天或同步邮箱。
2. 在消息中心选中会话，打开“AI 管理”，设置自然、轻松或专业语气，以及分析/草稿或暂停状态。
3. 点击“预览本次分析范围”，展开查看消息、已确认记忆和目标模型。预览不会调用模型。
4. 核对并勾选同意提交后开始分析。公网模型会接收到这些内容；只提交当前账号、联系人和会话选中的数据。
5. 核对摘要、风险及引用，再编辑保存或复制草稿。保存仅在本地，不发送到 QQ、邮箱等平台。
6. 查看记忆候选的证据后确认或删除。候选默认 `unverified`，只有用户确认后才用于后续分析。

未保存的草稿修改会按会话暂留在本次工作台内存中，切换页面或会话后可找回；断开、令牌失效、重新配对或退出应用会清除。编辑时先保存或还原，再修改记忆/偏好或重新分析。新消息导致草稿过时后，可显式复制未保存修改以便核对保留，不能把它保存为当前有效草稿。

每次最多选择近期20条、合计20KB消息，以及8条、合计4KB已确认记忆；序列化输入另限32KB，超限则不调用。截取窗口有提示，不能代表全部历史。记忆列表最多展示最近200条，未加载的旧证据显示编号及说明；完整证据跳转和记忆分类待扩展。

## 变化与失败

- 新消息（包括迟到的旧时间记录）、记忆确认/删除、暂停/语气变动、模型或目标地址变更会使旧确认和草稿失效。已读、置顶、归档不改变内容版本。
- 调用期间新消息或暂停会阻止旧结果落库。暂停不能撤回已经发给模型的数据，也不能保证供应商停止计费。
- 全后台单并发，无自动重试。超时、停止等待、断网后先刷新确认是否已有结果，再决定是否重新调用，重试可能再次计费。
- 无效 JSON、超长/截断输出、越界证据、工具调用被拒绝，不保存新分析或候选，不展示上游原始错误正文。
- 风险由模型建议和后端固定词追加提示组成，不能证明语义正确或覆盖全部风险。“未标出风险”不构成自动发送许可。
