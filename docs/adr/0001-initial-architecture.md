# ADR 0001：首轮工程架构

- 日期：2026-11-12
- 关联：FEAT-T04 / CHG-T04-001
- 状态：已实现工程部分，待团队审查；非生产验收。

## 本轮范围

用户“开始架构”授权先开展 T04 独立工程部分。T01 的赛期、账号和预算尚未全部确认，真实平台接入、数据库实现与自动发送仍以原任务依赖为准。不得以本轮提前开发将 T01 反向标记完成。

## 决定

1. Go 模块化单体 sociald 独立运行，HTTP API 仅本机监听。
2. React + TypeScript + Vite 构建工作台，Tauri 仅提供桌面外壳；窗口关闭不控制 Go 生命周期。
3. 配对令牌从环境加载，服务无默认令牌，前端仅内存保存，避免令牌进入 URL、磁盘和日志。
4. 系统信息、连接器声明和空列表为真实 API。SQLite 尚未初始化，因此 ready 为 503；所有写操作为 501。
5. 连接器先声明微信 Clawbot 与 Telegram Bot 的预定边界，所有真实收发能力为 false。
6. 领域 Scope 隔离工作区/连接账号/联系人/会话；模型及记忆模块不能直接获得平台发送权限。
7. 保留 Go 标准库核心，避免在加密数据库验证前绑定第三方 ORM 或数据库驱动。
8. Windows/Rust 编译与原生桌面启动需另行验证，不以 Web 构建代替。

## 微信判断

腾讯官方 [openclaw-weixin](https://github.com/Tencent/openclaw-weixin) 提供 Clawbot 通道。它是待验证接入路径，不能据此承诺读取个人微信全部原有好友、群聊或历史记录。Go 直连、桥接方式、版本、账号可用性和权限均尚待验证。当前未安装 OpenClaw 或授权微信账号。
