# ADR 0011：每日消息整理与高相关提醒

日期：2026-11-16；安全与目标同意修订：2026-11-17（Asia/Shanghai）
关联：`CHG-T20-002` / `CHG-T21-002` / `CHG-T20-003` / `CHG-T21-003` / `FEAT-T20` / `FEAT-T21`
状态：目标同意/额度/失败状态修订已实现，整合全检与后端 race 通过；待指定非作者审查/真实验收，实际完成日期—。新增约束见 [ADR 0014](<0014-native-assistant-and-confirmed-business-tools.md>)，本轮工程证据见 [验证记录](<../acceptance/T13-native-assistant-validation.md>)。

## 决策

首版采用每天一次的持久化摘要计划，默认时间为上海时区 08:00，用户可以在设置中启停和修改时间。提醒先显示在工作台，不通过微信、QQ 或邮件主动发送。

后台每分钟检查一次计划，到点后以“工作区 + 上海自然日”先持久占用一份报告；重复启动、页面关闭或服务重启不会重复调用同一日模型。用户可以手动立即生成，也使用相同的日期和状态记录。`running/succeeded/failed/unknown` 均占当日记录，force 不能绕过；异常停止遗留 running 时只允许人工核实，不能声称可自动恢复或重发。电脑/后台停止期间不运行，恢复后至多处理当日过去 24 小时，不承诺补齐全部离线日期。

摘要范围为过去 24 小时已经入库且未暂停 AI 的消息。首版以未读、接收方向及问号、@、金额/时间/请求/会议等固定文本标记计分（至少 3 分），最多取 500 条候选、每会话 20 条；不是已验收的语义相关性分类或高频联系人排序。按会话分别限域、保持时间顺序，AI 每次只接收单个会话的有界消息和证据 ID；后端校验结构化输出，再在本地聚合摘要、风险提醒和引用，禁止把不同联系人上下文混在同一个模型输入里。

提醒是由已校验的分析结果和风险提示形成的建议，不触发自动发送，也不代表承诺、待办或情绪识别已经完成独立评测。报告保存来源会话、消息证据 ID、生成时间和失败/unknown 状态；平台信息可经来源会话追溯，不声称已有逐连接器持久历史处理水位。

## 群聊边界

当前 `conversations` 已有 `conversation_kind`，微信本地读取器支持明确选定的私聊和群聊文本；群成员、@提及和成员权限表仍未建模。因此日报可以覆盖已入库的私聊与群聊文本，但群聊提醒只依据会话消息和现有证据，不推断成员身份或群权限。后续仍需独立扩展成员/提及关系、群权限和平台事件归属，不能把私聊联系人档案逻辑直接套用到群聊。

## 数据与失败

- `digest_schedules` 保存启用状态、上海本地时间、时区、CAS 版本、最后占用日期和同意的模型目标 ID/版本。模型 revision 0 合法，计划自己的 CAS revision 从 1 开始。
- 立即运行须当次明确同意当前模型；启用计划须独立明确同意每日把过去 24 小时未暂停入库文本交给该模型及可能费用。关闭计划无需模型可用。迁移禁用旧无绑定计划；每次保存模型配置，原子撤销周期同意并增加计划 CAS。
- `digest_reports` 保存日期、状态、摘要、提醒、证据 ID 和错误代码；运行状态为 running、succeeded、failed、unknown，不虚构可恢复的 queued 队列。
- 摘要最多选 500 条候选、每会话 20 条，保持时间顺序，以整条消息裁剪有界输入。暂停会话不进入模型；模型调用前后重验来源状态和证据。
- 模型未配置、共享额度不足、消息范围为空、服务重启和无效输出都必须可见；失败不伪造摘要，provider 鉴权错误不是工作台身份失效。与分析/档案/Agent 共享持久额度及单并发 gate，每次尝试先占额度、失败不退还。
- 电脑关机、休眠或后台停止时不执行；GET 查询不调用模型，不承诺平台离线补收。

## 验收目标

1. 可设置每日 08:00 计划，启停和修改有版本冲突保护。
2. 同一天所有报告状态均阻止重发；重启后保留事实状态，不自动重放 running/unknown。
3. 报告至少包含重要消息、提醒、来源会话、证据 ID、失败/unknown 和下一步。
4. 以合成用例验证跨联系人证据泄漏为 0、未授权发送为 0、重复报告为 0；真实聊天与模型效果仍待 kirinbao 独立验收，不能将未执行的固定 50 条评测记为通过。
5. 群聊已入库文本可参与摘要；群成员、@归属、群权限和实时平台覆盖未实现部分必须明确显示，不能把文本导入当作全平台实时覆盖。
6. 无当次/周期模型同意、旧绑定/版本、重复字段和过期 CAS 不外呼；模型保存后必须重新同意，关闭计划不被无模型状态阻止。
