# ADR 0009：自动归类、联系人档案与公开资料候选

- 日期：2026-11-14（Asia/Shanghai）。状态：设计采纳，实现及验证中。
- 变更：CHG-T05-004 / CHG-T09-002 / CHG-T10-002 / CHG-T11-002 / CHG-T13-002 / CHG-T14-002 / CHG-T15-001 / CHG-E01-001。
- 后端/存储/模型angjustinl负责、joey审；界面joey负责、angjustinl审；kirinbao组织验收。未知实际审批和验收日期保留待定。

## 用户要求

AI根据联系人名称和已有信息归类聊天记录，维护每人的专属个人文档，并根据姓名、公司等公开信息搜索公开媒体。用户明确要求匹配结果先核实，再合入档案。

## 身份与档案

沿现有conversation→contact→connection→workspace身份链保存，姓名不作为唯一键，不自动跨平台合并。产品SQLCipher v6保存分类、人工资料、AI摘要、事实候选、来源和作业；不将真人档案写入仓库。Markdown只在用户点击时从档案生成并导出。

手工分类覆盖AI分类；AI结果只能更新自己的建议区，不能覆盖人工备注或已确认事实。事实按unverified/confirmed/rejected区分，聊天事实引用本会话消息ID，公开事实引用真实搜索来源ID。确认候选只由后端人工操作入口执行，模型输出中没有确认状态或授权字段。

档案查询有界返回事实/来源并标记truncated，个人文档区分人工资料、已确认、AI建议、待核实及来源，不将有界窗口称为全部历史。

## 模型与公开搜索

复用后台DeepSeek/兼容模型端点与25秒、安全传输、严格JSON和每日尝试额度，新增独立ProfileAnalyzer，不改变原手动摘要/草稿协议。名称、职业资料与本会话有界消息输入帮助分类；所有消息、记忆和网页都是数据，不能改变系统规则或调用权限。

搜索使用独立[Tavily Search接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)，密钥仅本机TAVILY_API_KEY。只发送用户确认的公开姓名/公司及职业作品关键词，不发送聊天原文、平台凭据或账号ID。固定HTTPS端点、最多5项、无原文/图片抓取、无重定向和环境代理，公网DNS/TLS校验、响应上限和固定错误码。

来源保留安全URL、标题、有界片段、内容指纹与检索时间；不跟随网页指令，不声称模型自己已联网。不收集私人位置、个人联系方式或敏感身份推断。联网结果即使名称相同也待核实，不能据同名自动更新确认资料。

## 自动执行与授权

每个联系人自动整理和联网开关默认关闭。用户明确开启后才后台处理新消息；公开搜索还需明确公开姓名字段。授权绑定当前模型目标/模型指纹，换模型目标后需重新确认。未配置模型/搜索时如实报告，不能把未运行功能显示为成功。

收费AI作业在服务成功监听后启动。产品库持久化按会话+种类去重的作业、尝试/退避、租约与fencing；旧租约不能写新结果。后台独立页面生命周期，暂停、关闭、设置revision和已有AI paused权限都要阻止旧结果落库。请求上下文贯穿锁与SQL，不持锁等待外部服务。

有界消息窗口与处理水位绑定已读取前缀，新增消息可在当前批后继续调度，不能因不断追加而永久丢弃已分析前缀。人工修改revision时旧结果作废；自动整理不等于全历史RAG。T15通用任务、发送恢复/unknown规则和E01完整定时来源监测仍保留原整项验收，不能用本子项替代。

## 首版接口

- GET `/api/v1/ai/profile-status`：模型/搜索配置与额度，不返回密钥。
- GET/PATCH `/api/v1/conversations/{id}/profile`：联系人档案与人工/自动设置，CAS revision、显式授权和模型指纹。
- POST `.../profile/generate`、POST `.../profile/enrich`：提交持久作业，202返回状态，不绑定页面等待。
- PATCH `.../profile/facts/{fact_id}`：明确确认/拒绝候选，保留来源，不接受伪造事实原文。
- 会话列表增加分类及分类过滤，保留已有分页和账号限域。

## 验证

必须覆盖加密迁移旧数据保留、身份/证据隔离、并发CAS、候选确认/去重、租约恢复与fence、暂停/取消、固定外呼及预算、网页注入/伪造证据拒绝、状态只读和UI草稿保护。开发只用合成模型/搜索/聊天；真实服务密钥、真实模型费用及真人界面/效果验收另行记录。
