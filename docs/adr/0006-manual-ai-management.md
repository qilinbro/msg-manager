# ADR 0006：手动会话 AI 管理

- 日期：2026-11-12；状态：实现与工程验证，正式审查待进行。
- 关联 FEAT-T09—FEAT-T14 / 各自 CHG-Txx-001；用户选择 DeepSeek／兼容接口。

## 决定与数据路径

在加密消息中心上先交付“预览→用户确认→限域分析→保存摘要/草稿/候选→人工核对”。模型不持有平台凭据，不接收执行工具，输出不能开启发送或确认事实。手动子项不解除 T15 等整项前置条件。

工作台当前会话 → 后端鉴权/工作区 → SQLCipher 限域快照 → 用户确认 → 固定 Provider → JSON/证据校验 → 后端追加风险 → 事务重验快照 → 本地建议。模型调用期间不持有数据库锁；落库重验消息、记忆和偏好版本。

## 作用域、版本与存储

- v3 新增 AI 偏好、分析、证据、记忆和调用尝试表，沿用工作区/连接/联系人/会话约束；v2 旧数据和 FTS 保留。
- 近期20条/20KB消息，8条/4KB已确认记忆。精确会话限定，不按昵称或猜测身份合并。当前为近期窗口，全文/向量排序和 Recall@5 评测未完成。
- 内部快照覆盖范围、消息内容、全会话消息计数/最大序号、已确认记忆和偏好版本。迟到消息使旧快照失效；已读/置顶/归档不影响内容版本。
- 对外确认指纹再绑定模型及目标地址的无密钥配置指纹，后台更换模型后不能沿用旧确认。历史结果配置不匹配即过时，编辑接口再次核对。
- 原模型草稿与人工编辑字段分开。证据是输入消息 ID；候选以内容和证据形成稳定 ID，重复候选不重写已确认记忆。新候选不自动进入下次上下文。
- 每次人工重新分析是新调用/新记录；尚无任务级幂等、租约、跨进程恢复或自动重试。读取最近结果不调用模型。

## Provider 与限制

固定环境配置；TLS 1.2+、DNS 全结果公网验证、固定拨号 IP，禁代理/重定向；显式 loopback HTTP 仅用于本机模拟器。模型25秒，总处理28秒，响应1MiB、JSON深度24、输入32KB；拒绝重复字段、未知输出字段、工具调用、截断及无效/越界证据。结构校验不保证陈述真实。

全局单并发；上海自然日尝试数先持久化预占，失败也计数。用量取自供应商响应，缺失记0，不推算账单；次数上限不能替代金额预算。当前仅 draft_only / paused，无自动发送或仅分析独立权限；关键词风险仅追加提示，所有发送仍拒绝。

仓储隔离/迁移/重开、合成 HTTP/TLS Provider、真实 SQLCipher 的合成模型 API 链路有测试。真实模型、真人数据、浏览器交互和原生桌面验收未完成。先补真实模型与交叉审查，再按 T15→T13完整任务→T16/T17 推进无人值守。
