## 已处理的问题

1. **缺失桌面图标：** 配置最初引用的资源尚不存在，可能阻断 Windows 构建。已使用 Tauri CLI 从本项目 SVG 生成全部引用图标；Rust 原生构建仍待工具链验证。
2. **服务地址与 CSP 不一致：** 前端起初允许 HTTPS / 任意本地端口，而后端无 TLS、CSP 仅允许 HTTP 17890。现已统一限制 localhost/127.0.0.1 的 HTTP 17890。
3. **检查脚本修改源码：** 最初使用 go fmt 判断格式，已改为 gofmt -l，只检查不改写文件。
4. **首次启动说明的令牌复制顺序：** 已将复制步骤安排在启动前，避免独立后台阻塞后无法操作同一终端。

## 核对通过的边界

- Go API 与 OpenAPI / 前端字段一致；CORS 只读预检不返回业务数据，实际读取仍须 Bearer。
- 默认 loopback 监听、Host 校验与允许来源和桌面 CSP 相容。
- 前端令牌仅内存，credentials:omit、redirect:error，请求可取消；未发现当前骨架的旧请求状态泄漏。
- 模型、记忆和领域接口没有暴露实际平台凭据；发送策略唯一实现为默认拒绝。
- 系统不伪造 SQLite 就绪、平台连接、消息或发送成功。
