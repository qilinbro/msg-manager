# Agent 助手简洁界面要求

2026-11-18 · `CHG-T08-011` / `FEAT-T08` · 已记录，界面待改。

**默认打开就能输入：顶部「Agent 助手」「关闭」，中间对话，底部输入框和一个主按钮「提交」。** 空状态只留「你想做什么？」；不放教程、宣传语、重复标题或大段说明。用户可以直接问助手，详细规则放文档。

| 场景 | 当时才显示的内容 |
|---|---|
| 从业务页求助 | 用一句话显示来源和所选条件，如「带入 QQ 私聊筛选？」；用「带入 / 忽略」。不展示原始 JSON 或提示词模板；可核对实际带入内容。带入只更新草稿，有内容时明确追加，不自动提交。 |
| 准备调用模型 | 提交前简短显示模型、目标、将使用的数据和可能费用；配置版本绑定本轮同意。每轮单独同意、默认不勾选。 |
| 等待确认工具操作 | 只显示这一项动作、目标、影响及可核对的固定参数，提供「确认 / 拒绝」。发送或长期外发另行确认，不合并授权。 |
| 缺配置、失败或结果未知 | 一句话说明问题，加最相关的一个操作，如「模型未配置 · 去设置」「结果未确认 · 查看结果」。已知编号只读查询；没有编号先核对原页面，不自动重发。 |
| 非常用操作 | 「更多」默认收起，收纳「读取运行结果」「新会话」及权限/审计详情。额度、字节上限和过期说明在需要时提醒；超限保留输入，不自动截断。 |

关闭或按 Esc 返回原页面，保留筛选、选择和草稿；不取消已提交的运行。新会话只清除本页助手上下文；有未决结果时先核实，不撤销后台操作或业务草稿。运行恢复时再提示需同一授权身份、已知编号及保存期限。

验收：桌面与 390px 宽度的默认页只有一个主操作、没有长说明与横向滚动；键盘能提交、打开更多并关闭返回。覆盖带入草稿、未配置、逐轮同意、操作确认、只读恢复和未知结果，确保精简界面后确认仍不能跳过、恢复不会重复执行。
