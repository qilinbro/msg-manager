## 本次优化

个人档案页新增“不在场回执”卡，集中显示：

- 离开期间做了什么：聊天档案整理或公开资料检索。
- 当前状态：等待授权、等待后台处理、后台处理中、最近一批已完成、处理未完成、已停止、已暂停。
- 全历史进度：已处理 / 总条数。
- 最近更新时间：来自后台任务的更新时间。
- 失败原因：沿用后端错误码的人类可读说明。
- 下一步：恢复、刷新检查、重新确认、等待额度或保持后台运行。
- 运行边界：后台状态已返回、模型是否配置、发送始终关闭。

回执卡只读取已有档案和任务接口，不把 HTTP 200 或模型自称完成当成业务完成；任务没有成功落库时仍显示等待、失败或待确认。
