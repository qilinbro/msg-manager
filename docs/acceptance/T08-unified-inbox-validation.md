# 统一消息中心工程验证

- 日期：2026-11-12（Asia/Shanghai）。
- 关联：FEAT-T03 / CHG-T03-001、FEAT-T05 / CHG-T05-001、FEAT-T07 / CHG-T07-001、FEAT-T08 / CHG-T08-001。
- 工程实现按加密验证、迁移与仓储、导入与查询、工作台顺序推进。只使用合成数据，未使用真人聊天、现有登录账号或平台令牌。

## 已验证

Windows x64，项目内 Go 1.27.4、GCC、Node.js 24.12.0。SQLCipher 驱动锁定 `github.com/mutecomm/go-sqlcipher/v4 v4.4.2`，构建使用 CGO 与 `sqlite_fts5` 标签。

- SQLCipher 正确密钥读写与重开；错误密钥拒绝；WAL 实际写入；主库/WAL/测试目录无合成正文和 SQLite 明文头。
- `foreign_keys=1`、`temp_store=MEMORY`、`cipher_memory_security=ON`；FTS5 表与触发器可建立。中文搜索目前为受限域字面子串，不是 FTS 排序或 trigram。
- 本机固定磁盘校验和祖先 reparse/link 检查已加入；Windows 祖先符号链接测试在系统允许创建链接时执行，否则测试显式注明跳过。
- 版本化迁移可初始化、重开；账号/平台/同名联系人隔离；错误输入与内容冲突整批回滚；精确字符串 ID 与时区归一化。
- 并发重复导入去重；会话排序、筛选与消息历史分页；跨筛选/会话及旧版本游标拒绝；同时间戳不漏消息；已读/置顶/归档状态保存。
- Telegram Desktop 单个私聊 JSON 转换：只提取可见文字，附件/服务/未知发送者跳过计数，精确 ID、大小与条数限制、恶意 JSON 拒绝。
- 本产品 API 的鉴权、工作区、受限写入路由、CORS、输入大小、重复 JSON 键、非法过滤、错误脱敏、存储未启用与发送仍 501 的测试。
- 前端格式、类型检查与生产构建通过。构建 JS 约 277.6 KB、CSS 约 31.3 KB（压缩前）。

整体复核入口为 `scripts/check.ps1`；Windows GCC 所在目录须进入 PATH，脚本会按实际编译器路径补入。

## 独立进程 HTTP 验证

实际构建 `.runtime/sociald-inbox.exe` 并在本机启动，用独立测试数据库通过 HTTP 导入四个平台各 250 条、共 **1000 条合成消息**，形成 8 个会话。重复导入 1000 条均被识别为重复。平台内中文搜索、会话分页、消息历史分页与升序、已读/置顶/归档/恢复操作和发送拒绝均通过。

结构化记录见 [inbox-http-validation.json](inbox-http-validation.json)。该测试只证明本产品本地消息管理，不是四平台实时授权或在线收件。临时数据库与合成令牌位于本机测试运行范围，不纳入源码交付。

## 启动与密钥

新增 `scripts/start-inbox.ps1`，首次生成 32 字节随机数据库密钥，使用当前 Windows 用户 DPAPI 保护并限制密钥目录访问；重启复用已有密钥，遇到有库无密钥时拒绝覆盖。脚本语法检查及 Windows DPAPI 加解密往返已通过；完整首次启动/再次启动和跨账号行为仍需交付验收。

跨设备备份、密钥导出、后台服务身份访问与恢复演练属于后续 T19/T24，不以本轮 DPAPI 往返代替。

## 辅助静态复核

仓储辅助复核已进行，修正消息页返回顺序；加上数据库本机磁盘/链接祖先检查。界面辅助静态复核发现并修正：

1. 筛选或刷新后当前会话已不在结果中，移除旧选择，避免管理按钮使用过期状态。
2. 归档旧会话的异步结果只清除仍选中的同一会话。
3. 搜索占位文字色调整，声明色静态对比度约 5.19:1。

针对上述三项的静态复核已通过。它不代表完整视觉通过或指定团队成员的正式批准。

## 未验证与限制

- 浏览器控制入口不可用；原生窗口回退也因无法确认当前浏览器 URL 而停止。本轮没有界面点击、移动布局、滚动锚点或截图证据。旧 T04/T02 截图不作本轮界面证据。
- 静态设计检测命令未产出可用报告，不将其计为通过。
- SQLCipher 驱动依赖较旧，上游 C 源码在 GCC 有编译警告；测试与构建通过，未调用其迁移/expanded-SQL 接口。正式发布前仍需依赖更新/安全复核，不能把本轮验证当作完整依赖安全证明。
- 未实现平台持续收件、SSE、完整联系人编辑、任务/发件箱迁移、模型、发送、全量备份恢复或原生 Tauri 构建。
- QQ 真实服务地址未提供；微信、Telegram、闪聊本轮均未建立在线个人账号连接。导入只能代表用户主动提供的本地记录。
