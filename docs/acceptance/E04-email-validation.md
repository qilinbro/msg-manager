# 邮箱接入工程验证记录

- 日期：2026-11-12（Asia/Shanghai）。
- 关联：FEAT-E04 / CHG-E04-001、FEAT-T06 / CHG-T06-001、FEAT-T05 / CHG-T05-002、FEAT-T08 / CHG-T08-002。
- 用户确认优先 QQ、163、支持 IMAP 应用授权码的企业邮箱。本记录只证明工程实现与合成环境验证，不代表真实提供商验收。

## 实现与检查

`scripts/check.ps1` 为整体检查入口，覆盖 Go 格式、测试、vet、API 契约，以及前端回归检查、格式、类型和生产构建。Windows x64 CGO / GCC 独立后台程序已构建成功。

### 协议与内容

- 稳定 go-imap v1.2.1 命令/响应解析与有界串行会话，go-message v0.18.2 MIME/字符集解码，依赖经官方 Go 代理获取并固定版本。
- 本地 TLS 模拟邮箱验证：证书信任/SNI、TLS 1.2+、全部解析地址公网校验与固定 IP、25 秒总限制、取消关闭连接、认证错误脱敏。
- 指令范围：LOGIN、CAPABILITY、服务端支持时的固定产品 ID、EXAMINE、FETCH、UID FETCH。正文使用 BODY.PEEK，拒绝非只读状态和零 UIDVALIDITY；未提供 SMTP、STORE、EXPUNGE、CLOSE 或远程删除。
- 合成邮件验证中文主题/姓名/正文、MIME 分段、纯文本优先、HTML 转文本、附件排除、不可信头部、稳定日期兜底、大小和条数限制。
- 服务端声明超大邮件按封跳过；谎报大字面量、过长行、总预算或嵌套超限终止整轮。已修复跨零/非零字面量边界累计嵌套限制，防止多行绕过深度上限。
- 包内测试覆盖率 85.3%，go vet 通过；模拟邮箱与邮件全部为合成数据，没有访问用户真实邮箱。

### 加密持久化与旧库

- v1→v2 迁移在同一加密事务内复制约束图，保留旧资源 ID、消息 seq、原始内容、已读/置顶/归档状态；按子表到父表删除、父表到子表重命名，重建 FTS 索引。
- 旧库迁移测试核对 foreign_key_check、FTS 原文可查、schema version=2、新邮件序号继续增长；无 writable_schema 或明文回退。
- 邮件来源为 imap，文件来源为 import；账号按服务器/端口/用户名限定，邮件按文件夹/UIDVALIDITY/UID限定，昵称、主题及 Message-ID 不用于合并。
- 相同邮件重复同步不覆盖本地 read；不同账号和文件夹不串联，内容冲突整批回滚。主题、发件人和收件人可在现有受限域查询中检索。

### HTTP 接口

- 未授权不拨号，非法来源/工作区先行拒绝；浏览器不能提交邮箱地址、主机、文件夹或密码配置，POST 同步仅接收空 JSON 对象。
- 状态 GET 不进行网络探测；同步单并发，错误返回固定分类，不回显上游正文、授权码或数据库密钥。
- 模拟适配器结合真实加密仓储验证同步保存、重复同步、只读/账号不匹配拒绝、部分失败不入库、同步繁忙与默认发信拒绝。
- 独立后台程序实测未配置状态、未授权 401、未配置同步 503、合成配置 ready、五来源目录、INBOX 规范化、预检 204 和发送 501。该独立进程测试不请求真实 IMAP 服务器，见 [email-runtime-validation.json](email-runtime-validation.json)。

### 工作台

- 邮箱来源、配置/最近同步/结果面板、手动同步、停止等待、主题/发件人/收件人及纯文本正文展示。
- 首版没有邮箱凭据输入框、HTML 执行、外部图片加载或发信按钮。
- 已修复停止等待后新同步结果未更新会话列表的问题；摘要比较防刷新循环，状态读取代际防止迟到响应覆盖成功结果，状态错误与同步错误分开。
- 邮箱标准 JSON 导入保留并校验 email 元数据与 read；新增独立回归检查，防止字段丢失或未读状态被改写。
- 小屏选择会话时焦点移至详情；显式返回时恢复列表焦点，搜索/筛选不会抢焦点。上述修复经辅助针对性静态复核，不宣称实际键盘通过。
- 前端格式/类型/构建通过，产物 JS 约 288.5 KB、CSS 约 33.7 KB（压缩前，以实际构建结果为准）。

## 限制与待验收

- 没有登录真实 QQ/163/企业邮箱，没有用户真实账号或授权码；提供商安全验证与真实同步仍待本机配置和授权后核验。
- 163 帮助站本轮未能读取，参数仅供配置参考，不声称已由网易官方核验当前行为。支持服务端声明的 RFC 2971 ID 不能替代真实兼容验收。
- 只同步一个账号/文件夹最近 N 封（默认50，最多100），不保证全历史、持续接收或补齐窗口外记录。最近同步统计重启后重置，邮件本身持久化。
- Gmail/Outlook OAuth、后台轮询、附件提取/保存、线程合并和发信均未实现。原始邮件传输仍可能含附件字节。
- 浏览器控制上一轮因无法确认 URL 而停止，本轮未补界面点击、响应式、截图或视觉验收。静态复核不替代这些检查。
- SQLCipher 上游旧依赖与 Windows 原生 Tauri 构建等限制沿用已有记录；不以本轮邮件测试作发布安全证明。
- 后端正式审查人 joey、前端正式审查人吕佳航、最终验收谢麒麟均待进行；本轮代理检查只作辅助。T05/T06/T08/E04 保持进行中，实际完成日期“—”，已完成统计不增加。
