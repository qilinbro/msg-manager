- `internal/store` 全部测试及 vet 通过；新增7项 AI 专项测试。
- 同名但不同账号/平台/联系人不串证据，跨会话引用整批拒绝；20条/20KB消息与8条/4KB记忆预算，未确认候选不进入模型上下文。

### API 到模型与数据库

`tests/integration/ai_test.go` 使用真实 Provider HTTP 客户端、真实 SQLCipher 仓储与合成模型服务：

- 预览不调用模型，缺少确认、旧指纹、未授权、暂停、繁忙及超额请求不调用模型；浏览器不能提交模型地址或密钥配置。
- 完成“预览→确认→摘要/草稿→候选待核实→编辑保存→人工确认记忆”链路；模型请求没有其他账号的合成私密消息、没有工具。
- 后端追加付款风险提示；模型越界证据返回502，不落库新结果，但请求尝试计入额度。
- 分析期间导入迟到消息或暂停，返回409且分析/候选不落库；取消返回504且不落库；同一时刻第二个请求返回AI_BUSY。
- 后台重启更换模型或目标地址后，旧预览确认409、旧草稿编辑409、历史结果标stale，不将旧同意沿用于新目标。
- 精确 GET/POST/PATCH/DELETE 预检、业务鉴权和来源限制通过；平台发送仍501，`sending_enabled=false`。
- 无模型配置时状态明确关闭，预览仍可读取但分析503；非法auto_send模式被拒绝。AI专项集成测试最终独立重跑通过，Windows x64 CGO后台程序构建成功。
- Go 格式、全包测试/vet、API引用和实现路由白名单检查通过；前端原有邮箱导入回归通过。
