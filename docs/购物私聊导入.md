# 导入购物私聊

支持闲鱼、淘宝、京东和拼多多的一对一纯文本聊天文件。把自己有权使用的记录整理成统一 JSON 后，在工作台的「购物渠道」选择相应平台，进入消息导入，检查来源并确认。导入后可在「消息」按平台筛选、按关键词搜索。

本方式需要用户主动提供文件。它不会登录购物平台、读取新的在线消息或修改平台上的已读状态；也不支持直接读取各平台原生文件、订单通知、群聊和附件。已有账号、密码和会话凭据都不需要填进文件。

## JSON 示例

保存为 UTF-8 编码的 `shopping-chat.json`。以下是合成数据：

```json
{
  "platform": "xianyu",
  "account_id": "example-my-account",
  "account_name": "示例账号",
  "messages": [
    {
      "external_id": "example-message-1",
      "peer_id": "example-chat-1",
      "peer_name": "示例会话",
      "conversation_kind": "private",
      "direction": "incoming",
      "body": "你好，这件还在吗？",
      "occurred_at": "2026-11-18T10:00:00+08:00"
    },
    {
      "external_id": "example-message-2",
      "peer_id": "example-chat-1",
      "peer_name": "示例会话",
      "conversation_kind": "private",
      "direction": "outgoing",
      "body": "还在。",
      "occurred_at": "2026-11-18T10:05:00+08:00"
    }
  ]
}
```

平台代码：闲鱼 `xianyu`，淘宝 `taobao`，京东 `jd`，拼多多 `pinduoduo`。同一账号、同一聊天和同一消息重复导入时，分别沿用稳定的 `account_id`、`peer_id` 和 `external_id`。显示名称可以重复，不能用作身份键；不同店铺或账号用不同账号 ID。相同消息 ID 的正文、方向或时间不同会报冲突并回滚本次导入。

每批最多 1,000 条、8 MiB；正文每条最多 16,000 个 UTF-8 字节。要补新聊天，可以再导入一个含新增记录的批次；它仍是手动补历史。

如果页面提示后台不支持购物导入，先按[统一消息中心启动说明](unified-inbox.md#启动)升级并重启本地服务。新后台会升级消息库结构，原库与配套密钥应留存；原生 Tauri 安装包需单独更新。
