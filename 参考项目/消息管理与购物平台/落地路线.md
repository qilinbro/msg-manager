# 本项目落地路线

2026-11-18 · CHG-E04-003 / FEAT-E04 · 这是参考调研，不是开发排期。`CHG-T06-013` 已将网页和导入移出自动接入主线，当前范围以[无人值守收件任务说明](../../docs/无人值守收件任务说明.md)及[购物消息任务清单](../../docs/购物消息任务清单.md)为准。

沿用现有工作台和独立 Go 后台。参考 Ferdium 的账号分组、Mailspring 的邮件线程和搜索、Chatwoot 的待处理队列和会话侧栏，以及 mautrix 的会话标识、补历史与断线恢复。

| 顺序 | 任务板块 | 负责人 / 审阅 | 验收指标（kirinbao） |
|---|---|---|---|
| 1 | E04：能力表分别登记网页入口、历史导入、持续收件、发送和订单查询 | angjustinl / joey | 账号角色、权限来源、证据和验证范围可追溯；未验证能力不显示为可用 |
| 2 | T04 / T06 / T15：复用消息适配、增量同步和任务恢复；先用测试数据 | angjustinl / joey | 同一事件重复到达只入库一次；不同账号与店铺的相同 ID 不冲突；写入失败不推进游标 |
| 3 | E04：只在取得可验证的聊天读权限后启动试点 | angjustinl / joey | 关闭工作台后接收平台新消息；独立验证账号隔离、撤销与失败状态；通过后才列为自动接入 |

按平台、账号、会话和上游消息 ID 去重，商家渠道额外绑定店铺。订单和聊天分开存储，关联订单前先核验权限。AI 只能访问任务所需的规范化消息和最少上下文，不接触平台凭据。购物试点不包含回复、付款、退款或发货；未来若开放发送，仍走审批与发件箱，结果不明时交人工核实。

购物个人账号目前没有经验证的持续读取通道，本期不做接入。商家能力须用明确授权的店铺验证；Shopify 和 WooCommerce 的订单侧栏仍只作为订单展示参考。

验收顺序：模拟数据验证归一化和恢复 → 非作者审阅权限和隔离 → 授权测试账号验证实际范围 → kirinbao 登记验收。资料交付不计入连接器完成数。
