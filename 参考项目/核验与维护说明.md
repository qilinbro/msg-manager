## 换机后恢复一个精简副本

从本项目根目录在 PowerShell 执行。以 go-telegram/bot 为例；其他项目的仓库、分支、固定提交和目录见清单。

```powershell
git -c http.sslBackend=openssl clone --depth=1 --filter=blob:none --sparse --no-tags --single-branch --branch main https://github.com/go-telegram/bot.git ./参考项目/源码/go-telegram-bot
git -c http.sslBackend=openssl -C ./参考项目/源码/go-telegram-bot sparse-checkout set models examples
git -C ./参考项目/源码/go-telegram-bot rev-parse HEAD
```

分支会继续更新，重新克隆得到的 HEAD 不一定等于清单版本。需要复现清单版本时，确认目标提交可获取后执行：

```powershell
git -c http.sslBackend=openssl -C ./参考项目/源码/go-telegram-bot fetch --depth=1 origin f061396531935982a05fcb1e09d2e5e7c2742a7c
git -C ./参考项目/源码/go-telegram-bot checkout --detach f061396531935982a05fcb1e09d2e5e7c2742a7c
```

只读原始源码，无需安装依赖。若之后需要完整构建，应先在单独环境评估依赖，再扩展检出：

```powershell
git -c http.sslBackend=openssl -C ./参考项目/源码/go-telegram-bot sparse-checkout disable
```

这会补取未下载的文件；大型项目可能增加明显的下载量。当前副本未取完整历史、不递归初始化子模块，也没有下载 LFS 大文件。
